## 群益 API 對應表

| 策略王 API | Eskmo 版本 |
|------------|------------|
| 2.13.53    | `>=0.0.6`  |
| 2.13.52    | `==0.0.5`  |
| 2.13.51    | `==0.0.4`  |

可透過 `pip install eskmo~=X.Y.Z` 方式安裝對應策略王 API 版本的 Eskmo

其中 `X.Y.Z` 為 Eskmo 版本號

> [!WARNING]
>
> 群益 SKCOM API 從 2.13.53 版本起, 需下載 **驗證小工具 (SKCOMVerifyDJ)** 驗證後才可使用
>
> 詳細請見 [群益 API 申請說明](https://www.capital.com.tw/web/#/download/ApiTrading/ApiTradinginfo)
