# 常見問題

> [!NOTE]
>
> 業務相關問題請聯繫對應券商詢問，Eskmo 僅提供 Eskmo 技術支援與協助

## 群益 SKCOM API

### 1. SKCOM 版本更新有了新的功能，Eskmo 會需要多長時間才會支援？

根據新的功能的重要性，可能在 1-3 個月不等，若您覺得這個功能非常重要，歡迎加入提出，我們會根據您的說明調整處理時間

### 2. 若要解除 SKCOM 使用限制，該怎麼做？

請聯繫您的群益營業員，只要您的日常交易量達到一定程度，他將會協助你開通更多連線數與檔數限制

### 3. 使用 SKCOM API 發生了非預期的行為，可以向誰詢問與反應？

群益 API 有專區可以提問，若問題相對明確，可以將目錄底下的 `CaptialLog/` 目錄提供給營業員，由營業員向群益資訊部詢問
