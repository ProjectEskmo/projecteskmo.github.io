# 使用限制

## 群益 API

群益的策略王 API 目前有以下限制：

| 項目           | 限制        |
|----------------|-------------|
| 連線           | 2 條        |
| 行情           | 100 檔      |
| 明細與最佳五檔 | 10 檔       |
| 委託相關操作   | 200 筆 / 秒 |

更多請見 [API 下載專區](https://www.capital.com.tw/web/#/download/ApiTrading/ApiTradinginfo) 的 **API 元件使用說明下載** 文件中的：

1. 3-3 行情物件連線限制說明
2. 4-4-1 `SKQuoteLib_LeaveMonitor` 備註
