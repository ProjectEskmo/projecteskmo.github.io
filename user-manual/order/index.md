# 下單

透過自身程式邏輯分析市場後，最終都要轉化成下單動作，並在市場上建立部位

API 下單根據市場別，在國內可以分為以下三類：

1. [證券委託](/user-manual/order/stock/index)
2. 期貨委託 <small>(Comming Soon)</small>
3. 選擇權委託 <small>(Comming Soon)</small>

每一類委託可以分成 **一般委託** 和 **智慧單** <small>(comming soon)</small> 兩種
