# 證券 MIT

MIT 智慧單 <small>(Market-If-Touched)</small> 經常被用於：
1. 觸價進出場 (突破進場, 停損停利)
2. 常效掛單 (掛到成交為止, 持倉長線管理)

透過 API 可以送出 MIT [掛單](/user-manual/order/stock/mit/send) 與 [刪單](/user-manual/order/stock/mit/cancel)（不可改單，改單請刪掉重掛）
