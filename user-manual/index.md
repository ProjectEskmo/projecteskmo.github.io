# 使用手冊

Eskmo 整合多家台灣券商交易 API 的 Python 套件，致力於提供友善的證券量化交易體驗

如果想要快速體驗一番，可以從 [立即開始](/getting-started/login) 10 分鐘即可上手

在本手冊中，將會依序介紹 Eskmo 提供的各項功能，以及範例程式碼

從左側索引開始瀏覽：

| 章節     | 說明                                              |
|----------|---------------------------------------------------|
| 環境配置 | 配置執行所需的開發環境，安裝券商 API 相關依賴元件 |
| 帳戶     | 透過 API 操作證券帳戶                             |
| 商品檔   | 介紹如何透過商品檔，進行相關資訊查詢              |
| 行情     | 講解如何訂閱與解訂行情                            |
| 下單     | 包含送出、修改與刪除委託的相關說明                |
| 回報     | 掌握各委託與商品檔的交易狀態                      |
| 帳務     | 深入了解自己帳戶庫存與損益                        |
| 系統     | 輔助 Eskmo 開發的各項方法與功能                   |
